✅ Strengths

  • ✔️ All hardware is commercially available and cheap
  • ✔️ ESP32 has built-in WiFi — no extra modules needed
  • ✔️ Massive Arduino/ESP32 community for support
  • ✔️ Firebase free tier handles small-medium scale
  • ✔️ Contactless — post-COVID friendly
  • ✔️ Proven by 1000s of similar IoT projects worldwide
  • ✔️ Total cost under $50 for a working prototype

⚠️ Challenges to Address

  • ⚡ WiFi range limited (~30m indoor) — need repeaters
  • ⚡ PIR sensors can give false triggers in hot areas
  • ⚡ RFID cards can be shared (proxy attendance risk)
  • ⚡ Needs stable power supply (USB/battery backup)
  • ⚡ Data security — needs encryption (solvable with TLS)
  • ⚡ Scalability requires proper cloud architecture
  • ⚡ Fingerprint sensor adds cost (~$8–15)
