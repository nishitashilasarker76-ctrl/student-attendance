💻 আপনার Laptop এ কিভাবে করবেন

Chat এ যা করেছি — ঠিক সেটাই আপনার PC তে step-by-step

Phase 1: Setup — একবার করলেই হবে (৩০ মিনিট)

1

Python Install করুন

⏱️ 5 min
🪟 Windows 🍎 Mac
  1. python.org/downloads → Download Python 3.11+
  2. Install করার সময় ✅ "Add Python to PATH" — এটা অবশ্যই tick দিন!
  3. Install শেষে CMD/Terminal খুলুন, verify করুন:
python --version
দেখাবে: Python 3.11.x বা 3.12.x — তাহলে OK! ✅
2

Project Folder তৈরি + Files Download করুন

⏱️ 5 min
  1. Arena.ai workspace থেকে thesis-project-complete.zip download করুন
  2. Desktop এ একটা folder বানান: thesis-project
  3. ZIP extract করুন সেই folder এ
mkdir C:\Users\YourName\Desktop\thesis-project cd C:\Users\YourName\Desktop\thesis-project
💡 অথবা manually: Desktop → Right click → New Folder → "thesis-project" নাম দিন → ZIP file extract করুন এখানে

Extract করলে এই structure দেখবেন:

thesis-project/ ├── attendance-ml/ │ ├── step1_generate_data.py │ ├── step2_train_models.py │ ├── step3_predict.py │ ├── approach1_sklearn.py │ ├── approach2_tensorflow.py │ ├── approach3_tflite_edge.py │ ├── fingerprint_system.py │ ├── data/ ← CSV files │ └── models/ ← trained models ├── project-visuals.html ├── complete-system-flow.html └── ... (other HTML files)
3

Python Libraries Install করুন

⏱️ 10 min

CMD/Terminal খুলুন → thesis-project folder এ যান → এই commands চালান:

cd C:\Users\YourName\Desktop\thesis-project\attendance-ml
pip install numpy pandas scikit-learn matplotlib seaborn
pip install tensorflow
💡 tensorflow install এ ৫-১০ মিনিট লাগতে পারে — ধৈর্য রাখুন। Internet দরকার।

Verify করুন:

python -c "import sklearn; import tensorflow; print('All OK!')"
দেখাবে: All OK! — তাহলে সব library installed ✅

Phase 3: Simulation — Wokwi (৩০ মিনিট)

10

Wokwi তে Circuit Build করুন

⏱️ 30 min
  1. wokwi.com → Sign up (free, Google account দিয়ে)
  2. "New Project" → "ESP32" select করুন
  3. "+" button → এই components add করুন:
    • PIR Sensor (HC-SR501)
    • Ultrasonic (HC-SR04)
    • OLED Display (SSD1306)
    • LED (Green) + LED (Red)
    • Buzzer
    • Push Button (fingerprint simulate)
    • Resistor (220Ω) × 2
  4. Wire connections করুন (project-visuals.html এর hardware diagram দেখুন)
  5. sketch.ino তে Arduino code paste করুন — models/fingerprint/esp32_fingerprint_attendance.ino file থেকে copy
  6. ▶️ Play button → Simulation run!
  7. PIR click → OLED দেখুন → Button click → "Welcome!" দেখুন
  8. 📸 Screenshot নিন! (Paper এর জন্য)
💡 Alternative: এই ready-made project open করুন → Fingerprint Attendance System — modify করুন!
