3. 📝 Key Code — Database Connectivity (Arduino)

ESP32 থেকে Firebase এ data পাঠানোর code — এটাই মূল connectivity!

// ━━━ Step 1: JSON data তৈরি ━━━ StaticJsonDocument<512> doc; doc["student_id"] = "STU-001"; doc["name"] = "Rahim Ahmed"; doc["department"] = "CSE"; doc["status"] = "present"; doc["confidence"] = 285; doc["date"] = "2026-06-08"; doc["time"] = "08:45:23"; doc["distance_cm"] = 42.5; doc["pir_motion"] = true; String jsonPayload; serializeJson(doc, jsonPayload); // ━━━ Step 2: Firebase URL তৈরি ━━━ String url = "https://YOUR-PROJECT.firebaseio.com/attendance/STU-001.json"; // ━━━ Step 3: HTTP PUT request পাঠানো ━━━ HTTPClient http; http.begin(url); http.addHeader("Content-Type", "application/json"); int httpCode = http.PUT(jsonPayload); // ← এই line এ data Firebase এ যায়! // ━━━ Step 4: Response check ━━━ if (httpCode == 200) { Serial.println("✅ Data saved to Firebase!"); } http.end();
💡 এটাই পুরো database connectivity! মাত্র ১৫ লাইন code!
• StaticJsonDocument → data কে JSON format এ convert করে
• HTTPClient → WiFi দিয়ে internet এ request পাঠায়
• http.PUT() → Firebase Realtime Database এ data save হয়
• Firebase URL এ /attendance/STU-001.json → এই path এ data বসে
