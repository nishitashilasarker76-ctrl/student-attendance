🔑 Q1: "Face recognition কিভাবে accuracy দিবে?"

Answer: আপনার proposal এ মূলত RFID-based identification — এটাই 99.9% accurate এবং sufficient!
Face recognition চাইলে add করা যায় — কাজ করে 128D embedding vector matching দিয়ে (cosine similarity ≥ 60% = match)।
কিন্তু RFID + PIR combo দিয়েই proxy-free attendance সম্ভব — PIR confirm করে যে person physically present আছে!

🖥️ Q2: "Simulator এ কিভাবে হবে?"

Answer:
• RFID: Wokwi তে RC522 component আছে — click করলে virtual card scan হয়, UID read হয়, database match হয় ✅
• Face: Camera simulate করা যায় না, কিন্তু embedding vector matching simulate করা হয়েছে Python demo তে ✅
• PIR: Wokwi তে click করলে motion detect হয় ✅
• Behaviour: Sensor data generate → ML model train → activity classify = fully simulated ✅
সবকিছুর core logic simulate হয়, শুধু hardware part skip!

🏃 Q3: "Behaviour কিভাবে identify করবে?"

Answer: ২ ভাবে —

1. Sensor-based (Real-time): Accelerometer magnitude দিয়ে → sitting (<0.1), standing (0.1-0.5), walking (0.5-2.0), running (>2.0) | ML model 91% accuracy তে classify করে!

2. Time-based (Historical): Attendance history থেকে → Regular/Latecomer/Irregular/Early Leaver pattern detect করে | Zone-based monitoring → restricted area violation alert!
